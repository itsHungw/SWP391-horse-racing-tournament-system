# Authentication and Authorization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the phase-1 auth foundation: email/password registration, email verification, JWT access tokens, HttpOnly-cookie refresh sessions with rotation, password reset, and role-based access control.

**Architecture:** Keep the existing `users`, `roles`, and `user_roles` tables as the identity and authorization core, then add focused auth tables for sessions and one-time tokens. Implement auth as a dedicated Spring Boot module with small services for registration, token issuance, session lifecycle, and password reset; access tokens identify users, while active roles are still loaded from the database for authorization decisions.

**Tech Stack:** Java 21, Spring Boot 4, Spring Security, Spring Data JPA, SQL Server, Maven, JUnit 5, MockMvc.

`User.java` should expose:

```java
@Entity
@Table(name = "users")
@Getter
@NoArgsConstructor(access = AccessLevel.PROTECTED)
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "full_name", nullable = false)
    private String fullName;

    @Column(nullable = false, unique = true)
    private String email;

    @Column(name = "password_hash", nullable = false)
    private String passwordHash;

    @Column(nullable = false)
    private String status;

    @Column(name = "email_verified", nullable = false)
    private boolean emailVerified;

    @Column(name = "last_login_at")
    private LocalDateTime lastLoginAt;

    @Column(name = "password_changed_at")
    private LocalDateTime passwordChangedAt;

    @OneToMany(mappedBy = "user")
    private Set<UserRole> userRoles = new HashSet<>();

    public static User pending(String email, String passwordHash, String fullName) {
        User user = new User();
        user.email = email;
        user.passwordHash = passwordHash;
        user.fullName = fullName;
        user.status = "PENDING_EMAIL_VERIFY";
        user.emailVerified = false;
        return user;
    }

    public Set<String> getActiveRoleNames() {
        return userRoles.stream()
            .filter(UserRole::isActive)
            .map(userRole -> userRole.getRole().getName())
            .collect(Collectors.toSet());
    }
}
```

`JwtService` should issue tokens with:

```java
public String issueAccessToken(User user) {
    Instant now = Instant.now();
    return JwtEncoderParameters.from(
        JwsHeader.with(MacAlgorithm.HS256).build(),
        JwtClaimsSet.builder()
            .subject(user.getId().toString())
            .issuedAt(now)
            .expiresAt(now.plus(accessTokenTtl))
            .claim("email", user.getEmail())
            .build()
    );
}
```

```java
public String sha256(String rawToken) {
    byte[] digest = MessageDigest.getInstance("SHA-256")
        .digest(rawToken.getBytes(StandardCharsets.UTF_8));
    return HexFormat.of().formatHex(digest);
}
```

```java
@Transactional
public SessionIssueResult rotate(String rawRefreshToken, String userAgent, String ipAddress) {
    String hash = tokenHashService.sha256(rawRefreshToken);
    AuthSession current = authSessionRepository.findByRefreshTokenHashAndRevokedAtIsNull(hash)
        .orElseThrow(() -> new IllegalArgumentException("INVALID_REFRESH_TOKEN"));
    if (current.isExpired(clock)) {
        throw new IllegalArgumentException("EXPIRED_REFRESH_TOKEN");
    }
    current.revokeNow();
    AuthSession replacement = createPersistedSession(current.getUser(), userAgent, ipAddress);
    current.replaceBy(replacement);
    return toIssueResult(replacement);
}
```

```java
public void forgotPassword(String email) {

@Transactional
public void resetPassword(ResetPasswordRequest request) {
    PasswordResetToken token = oneTimeTokenService.consumePasswordResetToken(request.token());
    User user = token.getUser();
    user.changePassword(passwordEncoder.encode(request.newPassword()));
    authSessionService.revokeAllForUser(user.getId());
}
```
