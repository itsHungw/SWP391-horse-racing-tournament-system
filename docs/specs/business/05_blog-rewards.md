# Blog Rewards

## 1. Purpose

Blogs serve two jobs:

1. educate spectators,
2. provide a clean way to earn virtual points.

## 2. Reward conditions

- Blog must be `PUBLISHED`.
- User can receive reward from a blog only once.
- Reading time must meet the minimum threshold.
- Scroll depth must meet the minimum threshold.
- Daily point earning limit must not be exceeded.

## 3. Recommended defaults

| Rule | Value |
| --- | --- |
| Minimum reading time | 30 seconds |
| Minimum scroll depth | 80% |
| Daily blog point cap | 100 points |

## 4. Anti-farming rationale

These rules prevent users from rapidly opening many pages just to accumulate points without meaningful engagement.
