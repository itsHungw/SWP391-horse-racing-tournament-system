# Implementation Checklist

## Phase 1 — Foundation
- auth,
- RBAC,
- database migration,
- standard responses,
- frontend skeleton.

## Phase 2 — Role approval and notifications
- role requests,
- role profiles,
- admin approval screens,
- notification center.

## Phase 3 — Horses and tournaments
- horse CRUD and approval,
- tournament CRUD and lifecycle,
- tournament registration.

## Phase 4 — Race setup
- race creation,
- referee assignment,
- jockey invitation,
- participant confirmation.

## Phase 5 — Race operations
- pre-race checks,
- violations,
- referee reports,
- result submission,
- result confirmation and publication,
- rankings.

## Phase 6 — Engagement
- blogs,
- blog reward anti-farming,
- point accounts,
- clean prediction game with fixed entry cost and fixed rewards,
- point transaction history.

## Phase 7 — AI and polish
- AI Race Insight,
- dashboards,
- filtering and pagination,
- demo data,
- end-to-end walkthrough.

## Documentation maintenance rules

- Update docs whenever schema or business rules change.
- Keep non-goals explicit.
- Do not reintroduce betting-style terminology unless it appears in an intentional anti-betting clarification.
