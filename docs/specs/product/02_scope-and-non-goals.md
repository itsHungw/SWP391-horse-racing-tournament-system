# Scope and Non-Goals

## 1. In scope

- User authentication and multi-role authorization
- Role request approval
- Horse approval and ownership management
- Tournament and race lifecycle management
- Tournament registration
- Jockey invitation workflow
- Referee check, violation, report, and result workflow
- Official result confirmation and publication
- Horse rankings
- Notifications
- Blog publishing and reward claiming
- Virtual point accounts
- Clean prediction game with fixed entry cost and fixed rewards
- AI Race Insight

## 2. Out of scope

The system does not support betting, real-money wagering, deposits, withdrawals, cash conversion, odds, or user-to-user point redistribution.

Also out of scope for the first delivery:

- payment gateways,
- live streaming,
- advanced analytics warehouse,
- full machine-learning pipeline,
- large-scale multi-tenant SaaS administration,
- production-grade DevOps automation.

## 3. Future enhancements

- jockey ranking,
- richer AI explanations,
- audit dashboards,
- CSV/Excel exports,
- cloud file storage,
- CI/CD and containerized deployment.
