1. **Thiếu hoàn toàn logic xử lý Đăng nhập/Đăng ký (Authentication Business Logic)**

## 🟡 Warnings (Nên sửa)

1. **Lộ chuỗi Secret của JWT nếu cấu hình sai trên Production**
   - File: `backend/src/main/resources/application.properties` (Dòng 14)
   - Nguy hiểm: Giá trị `app.auth.jwt-secret=${AUTH_JWT_SECRET:change-me-in-real-env-change-me-in-real-env}` cho phép ứng dụng chạy với một Secret mặc định nếu quên cấu hình. Hacker có thể dùng chuỗi này để tự tạo Token và chiếm quyền toàn bộ hệ thống.
   - Cách sửa: Xóa phần giá trị mặc định, chỉ để `app.auth.jwt-secret=${AUTH_JWT_SECRET}`. Nếu thiếu biến này, ứng dụng nên báo lỗi không khởi động được để đảm bảo an toàn tuyệt đối.

2. **Cấu hình CORS chưa được thiết lập**
   - File: `backend/src/main/java/com/example/horseracingtournamentsystem/security/SecurityConfig.java` (Dòng 28)
   - Nguy hiểm: `cors(Customizer.withDefaults())` sẽ dùng cấu hình mặc định của Spring, điều này sẽ khiến Frontend React (chạy trên port 5173) bị trình duyệt chặn (lỗi CORS) khi gọi API sang Backend (port 8080).
   - Cách sửa: Khai báo một Bean `CorsConfigurationSource` để cho phép origin `http://localhost:5173`.

3. **Code chưa được Commit (Rủi ro mất Data)**
   - File: Toàn bộ các file Java mới viết trong nhánh `feat/auth`.
   - Nguy hiểm: Vì các file này chưa được `git add` và commit, nếu máy tính gặp sự cố hoặc bạn gõ nhầm lệnh Git, toàn bộ công sức code sẽ bị mất.
   - Cách sửa: Chạy `git add .` và `git commit -m "feat: setup security and auth repositories"`.
